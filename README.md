**Restaurant Ordering and Reservation Management System**

**About This App**: This app showcases different custom-built ADT collections without using C#'s pre-built collections.

***Restaurant Ordering and Reservation Management System*** is a console application that helps user/s order food and beverages, and reserve a table in a restaurant. It focuses mainly on five (5) custom-built collections, and an additional collection, including;

1. **Priority Queue**: Handles priority-based order 
   processing and urgent reservation requests according 
   to assigned priority levels.

2. **Queue**: Manages the standard food preparation 
   line and regular reservation waiting list using the 
   First-In, First-Out (FIFO) principle.

3. **Stack**: Maintains order modification and 
   cancellation history to support undoing recent 
   reversible actions.

4. **Set**: Maintains a registry of unique reserved
   table IDs for specific time slots to prevent 
   duplicate or conflicting reservations.

5. **Map/Dictionary**: Enables fast lookup by mapping 
   Order ID -> Customer Information and Order Details.

6. **List**: An additional ADT collection, focusing
   on handling arrays (such as orders,
   reservation, and restaurants' food menu).

**App Features**: This app has a lot of features, from handling orders, to banking systems.

1. **Order Management**: It includes creating,
   editing, deleting and tracking an order.

2. **Reservation Management**: Handles
   reserving a table, as well as editing,
   deleting and tracking it.

3. **Billing and Payment Management**: Handles
   the billing process, along with accessing
   how to pay it.

4. **Order and Reservation Transaction
   History**: This feature includes receipts
   and lists of the user's current and past
   transactions, order and reservations made.

**Note**: This console app is purely for educational use. No banking, or payment system, are involved in the making.
