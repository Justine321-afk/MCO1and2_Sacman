**Restaurant Ordering and Reservation Management System**

About This App:
This app showcases different custom-built ADT collections without using C#'s pre-built collections.

*Restaurant Ordering and Reservation Management System* is a console application that helps user/s order food and beverages, and reserve a table in a restaurant. It focuses mainly on five (5) custom-built collections, including;

1. Priority Queue: Used for orders and
   reservations with priority.
2. Queue: Used for normal orders and
   reservations.
3. Stack: Used for orders and reservations that
   exceeds.
4. Set: Used for calculations (in the billing
   and payment management)
5. Map / Dictionary: Used to locate/search for
   an order, and/or reservation.
6. List: An additional ADT collection, focusing
   on handling arrays (such as orders,
   reservation, and restaurants' food menu).

App Features:
This app has a lot of features, from handling orders, to banking systems.

1. **Order Management**: It includes creating,
   editing, deleting and tracking an order.
2. **Reservation Management**: Handles
   reserving a table, as well as editing,
   deleting and tracking it.
3. **Billing and Payment Management**: Handles
   the billing process, along with accessing
   how to pay it.
4. **Order and Reservation Transaction
   History**: This feature includes receipts
   and lists of the user's current and past
   transactions, order and reservations made.

**Note**: This console app is purely for educational use. No banking, or payment system, are involved in the making.
